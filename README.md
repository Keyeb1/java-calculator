Java Calculator

A console-based calculator written in Java to strengthen my programming skills and deepen my understanding of Java fundamentals.

This project is part of my personal learning journey after completing my Computer Science degree. 
Instead of only reviewing theory, I am rebuilding my Java knowledge by developing a real application step by step. 
Every new feature is implemented incrementally, with a strong focus on understanding the underlying concepts rather than simply making the program work.

The project is also used to practice professional software development workflows, including Git, GitHub, clean commit history, and continuous refactoring.

⸻

Project Goals

* Refresh and improve my Java programming skills.
* Strengthen problem-solving and logical thinking.
* Learn to write clean, readable, and maintainable code.
* Practice professional Git and GitHub workflows.
* Document my learning progress through meaningful commits.

⸻

Current Features

* Read two numbers from the console
* Support for the four basic arithmetic operations:
    * Addition
    * Subtraction
    * Multiplication
    * Division
* Input validation for numeric values
* Input validation for arithmetic operators
* Protection against division by zero
* Repeat calculations without restarting the application
* Validation of the “Yes/No” prompt before continuing

Running the Project

Prerequisites

* Java 17 or higher
* IntelliJ IDEA (recommended)
* Maven

Run

Clone the repository:

git clone <repository-url>

Open the project in IntelliJ IDEA and run the Calculator class.
