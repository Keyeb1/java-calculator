Java Calculator

A Java-based calculator that is being developed step by step from a simple console application into a modern, interactive calculator with future AI and LLM capabilities.

The project started as a way to refresh and deepen my Java knowledge after completing my Computer Science degree. Instead of only reviewing theory, I am rebuilding my Java skills by developing a real application incrementally and understanding the concepts behind each implementation.

As the project evolves, the goal is to move beyond a traditional calculator. The long-term vision is to explore how modern software engineering and AI technologies can be combined to create a calculator that users can interact with more naturally — including conversational input and LLM-based functionality.

The project also serves as a practical environment for learning and applying professional software development workflows, including Git, GitHub, clean commit history, refactoring, testing, and application architecture.

Current Features

* Read two numbers from the console
* Support for the four basic arithmetic operations:
    * Addition
    * Subtraction
    * Multiplication
    * Division
* Input validation for numeric values
* Input validation for arithmetic operators
* Protection against division by zero
* Repeat calculations without restarting the application
* Validation of the Yes/No prompt before continuing
* Reusable methods for validated user input

Roadmap

The project is developed incrementally. Each stage builds on the previous one instead of introducing all functionality at once.

Phase 1 — Java Fundamentals

* Basic arithmetic operations
* Console input
* Operator selection
* Input validation
* Division-by-zero handling
* Repeated calculations
* Extract reusable methods

Phase 2 — Software Engineering

* Further refactoring
* Object-oriented design
* Exception handling
* Calculation history
* Additional mathematical operations
* Unit testing
* Improved project structure

Phase 3 — Application Evolution

* Move beyond the basic console interface
* Introduce a more interactive user experience
* Separate calculation logic from the user interface
* Explore APIs and external services
* Build a foundation that can support more advanced features

Phase 4 — AI & LLM Integration

The long-term goal is to explore how a calculator can become more natural and intelligent to use.

Potential directions include:

* Natural-language mathematical input
* Conversational interaction with the calculator
* Understanding requests such as “What is 15% of 240?”
* Translating natural-language requests into calculator operations
* Providing explanations of calculations when requested
* Integrating an LLM through an API
* Combining deterministic calculation logic with AI-based language understanding

The goal is not to let an LLM replace reliable mathematical calculations, but to use AI as an interaction layer while keeping deterministic operations in the application itself.

Long-Term Vision

Traditional calculators require users to communicate with the software through predefined buttons, operators, and commands.

This project explores a different direction:

What could a calculator look like if it were designed for the way people interact with software in the age of AI?

The long-term vision is to develop the project from a small Java console application into an interactive system that combines traditional calculation logic with modern conversational interfaces and LLM capabilities.

The calculator should eventually be able to understand what a user wants to calculate, perform the actual calculation reliably, and communicate the result in a natural and useful way.
